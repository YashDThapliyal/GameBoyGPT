Console and display options, and what's real here

The plastic is CSS. The screen shows the real ROM's machine code running in binjgb, an open-source emulator compiled to WebAssembly. Your message goes into the ROM's own input buffer. JavaScript takes no part in generating replies, and nothing leaves your browser. Replies, tokens, times and the x-ray are read from emulated memory. The shutdown fight's page effects and big lines are scripted, using what's in its save. None of this has run on a physical console.
