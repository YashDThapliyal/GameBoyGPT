Console and display options, and what's real here

The plastic is CSS. The screen shows the real ROM's machine code running in binjgb, an open-source emulator compiled to WebAssembly. Your message goes into the ROM's own input buffer. JavaScript takes no part in generating the reply, and nothing is sent over the network. Everything on this panel marked as a reply, a token or a time is read from emulated memory. This has not been tested on a physical console.
