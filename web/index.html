What is real here

The plastic is CSS and does nothing but look the part. The screen shows the real ROM's machine code running in binjgb, an open-source emulator compiled to WebAssembly. No JavaScript takes part in generating the text and nothing is sent over the network. The model understands only a narrow set of topics. This has not been tested on a physical console.
