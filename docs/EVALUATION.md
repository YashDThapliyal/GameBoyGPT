# Evaluation

Generated by `tools/report.py` from `reports/evaluation.json`, which `training/evaluate.py` computes on the integer reference. The ROM matches that reference bit for bit. Summary numbers are in [RESULTS.md](../RESULTS.md).

## How to read this

**Grammar valid** means the response parses as a sequence of authored sentences. It's a strict, mechanical check. It says nothing about whether the response is funny or follows from what you said.

**On target** means a sentence came from the pool for that intent and topic. This is the closest thing here to "it answered you", and it's only as good as the pools.

The model works in a narrow domain. It isn't general chat. Only a person can judge whether it's entertaining: these samples are unedited so that you can.
